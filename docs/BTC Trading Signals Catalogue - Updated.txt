## 3. Fundamental, On-Chain & Derivatives Bias Overlay

This is a **bias overlay**, not an entry system.

The technical framework still decides the trade. The overlay only adjusts confidence, caution, and position quality.

## Core Overlay Rule

| Rule | Meaning |
| --- | --- |
| **TA decides the trade** | Support/resistance, volume profile, structure, confirmation, and invalidation come first. |
| **Overlay adjusts confidence** | ETF flows, funding, Reserve Risk, and Puell Multiple can strengthen or weaken the bias. |
| **No standalone trades** | Never enter only because an ETF/on-chain/funding signal is bullish or bearish. |
| **Conflict means caution** | If TA is bullish but the overlay is hostile, reduce size or wait for cleaner confirmation. |
| **Agreement means confidence** | If TA and the overlay agree, the setup quality improves. |

## 19. Best Webpage Structure

Use this order:

1. **Market Bias Signals**
2. **Multi-Timeframe Signals**
3. **Fundamental, On-Chain & Derivatives Overlay**
4. **Support & Resistance Signals**
5. **Volume Profile Signals**
6. **Range Signals**
7. **Trendline Signals**
8. **Moving Average Signals**
9. **Bullish Long Setup Signals**
10. **Bearish Short Setup Signals**
11. **Entry Confirmation Signals**
12. **Exit & Risk Signals**
13. **Weekend / No-Trade Signals**
14. **Confluence Scorecard**

A good scoring system would be:

|                       Score | Meaning                      |
| --------------------------: | ---------------------------- |
|             **0–2 signals** | Weak setup                   |
|             **3–4 signals** | Possible setup               |
|             **5–6 signals** | Strong setup                 |
|              **7+ signals** | High-confluence setup        |
| **No defined invalidation** | No trade regardless of score |
| **Overlay conflicts with TA** | Reduce size, lower confidence, or wait |
| **Overlay agrees with TA** | Setup confidence improves, but confirmation still required |

Final webpage principle:

> **One signal is information. Multiple aligned signals create a trade setup.**

> **The BTC overlay adjusts bias and confidence. It does not replace technical confirmation, invalidation, or risk management.**
